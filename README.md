Bouncing Ball Toy
Controls
A - Move paddle left

D - Move paddle right

Description
Bouncing Ball Toy is a simple interactive 2D toy. The player controls a paddle and bounces a ball around the screen. The ball bounces off the walls and the paddle. If the ball misses the paddle, it resets to the center of the screen.

Features
Bouncing ball movement
Paddle controlled with keyboard input
Wall collisions
Paddle collisions
Ball reset when missed
Decorative star background
